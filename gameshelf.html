Sobre o projeto

O GameShelf organiza uma experiência de descoberta de jogos em páginas de apresentação, catálogo e detalhes. A integração com uma API de dados de jogos permite exibir informações como gêneros, plataformas, datas de lançamento, avaliações e imagens, conforme a disponibilidade dos dados externos.

// experiência

Principais áreas

Catálogo de jogos

Uma área para navegar por títulos e descobrir opções além dos jogos já conhecidos.

Páginas de detalhes

Consulta de informações do jogo, como descrição, gêneros, plataformas, lançamento e avaliação.

Conteúdo visual

Artes e capturas de tela ajudam a apresentar o estilo e o universo de cada título.

Interface responsiva

Estrutura visual construída para organizar o conteúdo e facilitar a navegação em diferentes telas.
