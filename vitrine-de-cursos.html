Sobre o projeto

O Vitrine de Cursos é um projeto em desenvolvimento com foco na apresentação de cursos em uma interface organizada. A página pública descreve a proposta do sistema sem depender de acesso ao repositório de código.

// objetivos

Foco do projeto

Apresentação clara

Estruturar informações dos cursos para que sejam fáceis de consultar e comparar.

Organização de dados

Modelar e armazenar informações necessárias à aplicação de forma consistente.

Experiência web

Desenvolver uma interface acessível e organizada para explorar o catálogo de cursos.

Esta apresentação descreve o objetivo geral do projeto. Funcionalidades específicas serão adicionadas à medida que forem confirmadas e implementadas.
